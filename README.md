# legume-graph-embedding

Count-NCE bipartite graph embedding over (cell, feature) edges. Extracted from
[`legume-rs`](https://github.com/causalpathlab/legume-rs)
(`graph-embedding-util`).

The Rust library crate remains `graph_embedding_util`:

```toml
graph-embedding-util = { version = "0.8.4", package = "legume-graph-embedding" }
```

Optional features: `--features cuda`, `--features metal`.
